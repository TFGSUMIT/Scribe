# ADR-005 — Privacy First

**Status:** Accepted

**Date:** 2026-07-04

## Context

Users trust Scribe with complete RPG sessions, which may contain private conversations.

## Decision

User data belongs to the user.

Whenever possible:

- Audio should remain local.
- Campaign data should remain local.
- AI providers should be optional.

## Consequences

Scribe prioritizes user privacy over convenience whenever possible.
